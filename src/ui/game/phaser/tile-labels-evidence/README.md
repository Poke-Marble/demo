# 타일 고정 이름판 검증

기준: `783449e`, 브랜치/워크스페이스 표시 이름 `fix/board-tile-labels`.

선택 우선 충돌 회피 배치와 SVG 연결선, 모바일 전용 목록/플로팅 복제본을 제거했다. 타일 앞쪽 윗면에 작은 이름판을 두고 기존 Phaser 카메라 행렬로 투영한다. 건물·플레이어 애니메이션이나 선택은 위치 계산에 참여하지 않는다. 이름판은 얇은 영역에서만 모델보다 위에 그려지고, 포인터는 기존 타일 히트 테스트와 팬 입력으로 전달된다. 키보드 Enter/Space로도 도시 정보를 열 수 있다.

`tileNamePlate` 상수 근거: x=500은 `projectWorld`의 1000px 장면 중심이다. width/160은 76×16 이름판의 u축 길이를 타일 폭의 47.5%, v축 길이를 10%로 만든다. 38/8은 이름판 중심이며, 앞 모서리 축으로 19.5% 이동한다. 모든 모서리가 타일 다이아몬드 내부이고 글자가 좌우 반전되지 않는 것을 관련 단위 검사로 확인했다. 축 기울기는 현재 타일의 height/width (=230/400)를 사용한다. 투영·모델·음영 코드는 수정하지 않았다. index.ts BOM 추가도 제거했다.

## 결과

- Chrome 157.0.8103.80, DPR 2, 1280×720 / 390×844 / 844×390.
- `before-*-final.png`와 `after-*-final.png`: 최종 시설과 보라타운 4플레이어 겹침. `after-*-empty.png`: 빈 땅과 같은 4플레이어 위치.
- 실제 PNG를 열어 원근·모델과의 관계·모바일 미세 글자를 확인했다. 데스크톱 이름판은 타일 모서리 방향과 일치한다. 이름판 영역 밖에서는 건물과 플레이어를 덮지 않는다.
- 세 화면, 빈 땅/최종 시설 모두 도시 탭 전후 32개 이름판 좌표/변환 동일. 보라타운 정보창 제목도 확인했다. `after-1280x720-final-selected.png`가 정보창 증거다.
- 긴 실제 맵 이름 `소용돌이섬 · 루기아`, `방울탑 · 칠색조`, `공중날기` 모두 DOM scrollWidth ≤ clientWidth. 긴 이름은 76px 안에 맞춰 작은 글꼴을 사용한다. 상세 수치는 `report.json`에 기록했다.
- 비행 회귀는 같은 GameView로 만든 독립 렌더러 fixture에서 세 화면 모두 실제 보드 클릭 → 후보 선택, 포인터 드래그 팬, 키보드 Enter 후보 선택, 명시적 확정 → 선택 콜백 전달을 확인했다. 경제 거래나 새 전체 seed 시뮬레이션은 수행하지 않았다.
- 관련 labels/board-flight 단위 검사 5개, 변경 파일 ESLint/Prettier, `git diff --check`, TypeScript 포함 production build 통과. Vite의 기존 큰 chunk 경고는 남는다.

## 가독성과 검증 범위의 한계

390px 전체 보기에서는 타일과 글자가 매우 작다. 긴 특수칸은 특히 미세하며 원거리에서 모든 도시 이름이 읽힌다고 주장하지 않는다. 도시 탭 정보와 기존 접힌 도시/키보드 목록으로 전체 이름을 확인할 수 있다. 기존 카메라 휠/팬 입력 경로를 변경하지 않았고, 이번 브라우저 검사는 비행 중 실제 포인터 팬을 확인했다. 휠 확대와 모든 실기기 터치 조합을 별도 재검사하지는 않았다. 플로팅 이름·연결선·상시 목록은 재도입하지 않았다.

레이블은 얇은 타일 앞 영역에서 우선 표시되므로 그 영역을 지나가는 발 일부와 국소 겹침은 가능하다. 대형 이름표로 플레이어나 건물을 덮는 방식은 사용하지 않는다. HUD·스카이·게임 규칙·경제·배포 설정 변경은 없다.
