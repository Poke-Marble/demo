# 특수 연출 시각 자료

- 루기아/칠색조/비행 실루엣, 파도 고리, 깃털, 광선, VS 구성: 이 브랜치에서 작성한 HTML/CSS 도형. 외부 이미지·음원 다운로드 없음. 상용 게임 화면/사운드 복사 없음.
- 전설 실루엣은 최종 전설 스프라이트를 대신하는 임시 그래픽이다. PMDCollab 전설 파일은 사용하지 않았다. 파일별 제작자·재사용 조건을 확인하지 않은 자료를 허가된 것으로 간주하지 않는다.
- 내 파트너는 기존 프로젝트 `findSprite`의 Idle 에셋을 참조한다. 신규 파일 복사 없음. 기존 `src/assets/generated/sprites.json` 및 vendor 크레딧/라이선스가 출처 기준이다. 여기서 기존 권리 조건을 확대하거나 전설 에셋에 적용하지 않는다.
- 포켓몬 캐릭터의 원 권리와 도형/팬 제작 기여의 권리는 구별한다. 이 기록은 캐릭터 자체에 대한 사용 허가를 주장하지 않는다.

향후 PMDCollab 전설 아트를 도입하려면 각 사용 파일의 원본 URL, 제작자, 명시적 조건, 해시를 이 디렉터리에 추가하고 원 저작권과 기여자의 권리 범위를 함께 확인해야 한다.
