# 전설 시험·공중날기·보드 아트 병행 작업

세 브랜치는 이 문서를 포함한 동일한 main에서 분기한다. 자기 워크트리만 수정하고, 원격 푸시·배포·main 병합은 하지 않는다. 테스트와 로컬 커밋 후 한국어로 결과·가정·남은 통합 작업을 보고한다.

## feat/legendary-trials — poke-trials

- 소유 경로: `src/game/**`, `src/data/maps/**`, `docs/legendary-trials.md`.
- 출발/루기아 시험/칠색조 시험/공중날기를 32칸의 0/8/16/24 모서리에 배치한다. 구매 가능한 특별 명소 4개는 따로 유지한다. 8개 도시 그룹의 재배치와 검증을 포함한다.
- 시험 실패 시 체류·자기 차례 재도전, 성공 시 다음 차례 정상 이동. 탈출로프는 보상 없이 시험을 종료하고 현재 차례에 정상 이동한다. 일반 배틀 시스템은 만들지 않는다.
- 기획 기본값은 조정 가능한 초안: 세 번째 도전 보장 성공, 루기아 가호는 다음 통행료 1회 할인, 칠색조 가호는 다음 강화 1회 할인. 구체적인 시험 과제·성공률·할인율은 가정으로 명시한다. 경제 미구현 부분은 순수 함수/연결 계약으로 제공한다.
- 공중날기는 목적지 선택 후 이동하고 착지 효과를 처리한다. 출발 통과 보상 없음, 동일 행동에서 재귀 비행 금지. 시험 중 사용 불가. 합법 목적지와 중복 입력을 규칙 계층에서 검증한다.
- 기존 계약은 가능한 추가적인 선택 속성과 확장 모듈로 호환성을 지킨다. 특수 칸은 일반 명소 독점·매입 대상과 명확히 구분한다. UI 파일은 수정하지 않는다.
- 엔진과 분리된 연출 요청 데이터를 반환한다: `trial-intro`(legendary: `lugia` 또는 `ho-oh`, playerId, tileId), `fly`(playerId, from, to). UI가 이 데이터를 어댑터로 전달할 수 있게 문서화한다.

## feat/special-event-ui — poke-events

- 소유 경로: `src/ui/game/events/**`, `src/ui/game/adapter.ts`, `src/ui/game/index.ts`, `src/ui/game/demo/**`, 별도 이벤트 미리보기 엔트리, `docs/special-event-ui.md`.
- 보드 암전→루기아 파도/칠색조 깃털·빛→내 포켓몬 대 전설 VS→복귀 연출. 실제 전투는 없음.
- 비행 목적지 선택 UI→확정→암전→이륙→화면 횡단→목적지 그림자/착지→복귀. 시험 칸으로 비행 시 비행 종료 후 시험 연출을 순서대로 재생한다.
- 목표 2~3초, 클릭/키로 스킵, reduced-motion, 입력 잠금, 취소/재시작/언마운트 정리, 중복 이벤트 방지. 스킵해도 결과를 다시 계산하거나 중복 dispatch하지 않는다. 엔진 확정 상태를 표시하며 규칙 판단은 하지 않는다.
- 위 연출 데이터에 맞는 선택적 adapter 필드를 정의한다. 규칙 미병합 상태에서는 격리된 demo에서 시험 성공·실패·로프·비행을 시연하고 데모임을 명시한다. 진짜 경제/AI를 구현한 것으로 표현하지 않는다.
- PMDCollab 루기아/칠색조 에셋은 사용 파일별 출처/제작자/조건을 확인하고 events 하위에 기록한다. 상용 게임 VS 화면/소리를 복사하지 않는다.
- board.ts/isometric.ts/isometric.css/scenery.ts 및 공통 게임 계약은 수정하지 않는다. 필요한 보드 훅은 외부 오버레이와 DOM 접근 어댑터로 연결하고 요구사항을 문서화한다.

## feat/board-art — poke-art

- 소유 경로: `src/ui/game/art/**`, `src/ui/game/assets/regional/**`, `src/ui/game/board.ts`, `src/ui/game/isometric.ts`, `src/ui/game/isometric.css`, `src/ui/game/scenery.ts`, 별도 아트 미리보기 엔트리, `docs/board-art.md`.
- 일반 집 반복 대신 관동성도 장소별 집/센터/체육관/항구/전통 건축/수목과 수면 등 소량의 일관된 픽셀 에셋으로 차별화한다. 2.5D 지면 위 세워진 객체, 접지와 깊이 정렬 및 클릭 영역을 유지한다.
- 모서리 0/8/16/24는 START/소용돌이섬 루기아 시험/방울탑 칠색조 시험/공중날기의 장면으로 장식한다. 가능하면 tile ID/선택적 시각 메타데이터로 매핑하고 index는 데모 대체값으로만 쓴다. 별도 특별 명소와 구별한다.
- 후보 원 출처: https://github.com/PMDCollab/RawAsset (BG/Object/Tile/Item; 일괄 라이선스 가정 금지), https://eeveeexpo.com/resources/565/ (Foxowl 및 부분별 크레딧), https://eeveeexpo.com/resources/684/ (비상업·크레딧, 부분별 제작자). 실제 사용할 파일의 재사용 조건을 확인하고 다운로드 출처/제작자/조건/해시를 기록한다. README의 삭제 안내만으로 허가를 단정하지 않는다.
- 적합한 재사용 자료가 없으면 확인한 범위와 한계를 보고하고 코드로 만든 작은 장식으로 보완한다. AI 이미지로 대체하지 않는다. 공식 에셋과 팬 제작 기여의 권리를 구분한다.
- index.ts/adapter.ts/demo 파일/game.css 및 게임 규칙/맵 데이터는 수정하지 않는다. 자기 독립 프리뷰로 보여주고 후속 통합 연결점을 문서화한다.

## 검증과 후속 통합

각자 AGENTS와 관련 skills를 확인한다. 의존성은 npm ci로 설치하고 typecheck/lint/build와 담당 테스트를 실행한다. UI는 가능하면 Chrome 넓은/좁은 화면 및 키보드/스킵을 확인하고 캡처한다. 개별 프리뷰도 번들되는지 확인한다. 루트 설정/lockfile은 담당자 임의로 변경하지 않는다. 통합 시 규칙→연출→아트 순서로 반영하고 실제 맵+실제 엔진 연결은 별도로 검증한다.
