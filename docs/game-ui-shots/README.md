# 게임 UI 2.5D 전후 캡처

Chrome 실제 창을 로컬에서 캡처했다. 기존 캡처는 작업 재개 시 그대로 보존했다.

| 파일                                                           | 내용                                      |
| -------------------------------------------------------------- | ----------------------------------------- |
| [before-topdown.jpg](before-topdown.jpg)                       | 변경 전 4칸 탑다운 보드                   |
| [after-isometric-32-wide.jpg](after-isometric-32-wide.jpg)     | 32칸 입체 QA 배치, 시설 높이·앞뒤 말·HUD  |
| [after-isometric-purchase.jpg](after-isometric-purchase.jpg)   | 3칸 이동 완료 후 정면 구매 대화창         |
| [after-isometric-32-narrow.jpg](after-isometric-32-narrow.jpg) | 약 590px 폭에서 전체 보드와 세로 배치 HUD |

최종 결과는 [after-isometric-32-final.jpg](after-isometric-32-final.jpg)이며, 시설 세로 비율 보정까지 반영한 32칸 QA 배치다.

이전/이후의 맵 칸 수는 다르다. 변경 전은 기반 4칸 샘플이며, 이후 32칸은 렌더링 확인용 fixture다. 두 지도 모두 완성 게임 맵을 의미하지 않는다. 나머지 캡처는 최종 세로 비율 보정 전 검증 과정도 그대로 보존한 것으로 단계별 시설의 세부 비율에 소폭 차이가 있다. 이동 중 프레임·영상은 없으며 구매 캡처는 이동 완료 뒤다.
