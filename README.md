# 관동·성도 보드게임 — 개발 기반

비공식·비상업 포켓몬 팬 프로젝트의 `feat/init` 세팅입니다. **플레이 가능한 게임이 아니라**, 후속 작업에서 사용할 공통 계약·로컬 데이터·스프라이트 표시를 검증하는 화면입니다. 자체 코드는 새로 작성했으며 라이선스는 **미정**입니다.

## 기획과 이번 범위

잠정 MVP는 관동·성도를 묶은 맵 1개, 한 기기에서 2~4인이 번갈아 플레이하는 방식입니다. 기본 플레이어 후보는 **이상해씨·파이리·꼬부기·피카츄** 4종입니다. 준비 화면에서 참가 인원과 각자의 파트너를 고를 수 있으며 선택은 메모리에만 유지됩니다. 중복 선택 시 두 플레이어의 파트너를 교환합니다.

첫 완주의 후속 목표는 주사위 이동, 도시 협약(구매), 시설 강화, 통행료, 파산 및 다음 네 승리 조건입니다.

- 최후 1인 생존
- 도시 그룹 3개 완성
- 한 변의 일반 도시 독점
- 특별 명소 4곳 독점

이번에는 위 규칙·경제·승리 판정·전체 맵·게임 시작을 구현하지 않았습니다. 온라인·AI·전설 기믹 역시 제외합니다. 화면의 4칸은 계약 확인용이며 실제 맵 배치나 그룹 구성의 결정안이 아닙니다.

## 로컬 실행

Node.js **22.17 이상**과 npm을 사용합니다. PowerShell에서 실행 정책으로 `npm.ps1`이 차단되면 아래처럼 `npm.cmd`를 사용하세요.

```powershell
npm.cmd ci
npm.cmd run dev
```

표시된 로컬 주소(기본 `http://127.0.0.1:5173`)를 Chrome에서 엽니다. 설치 이후 기본 화면·빌드에는 PokeAPI나 SpriteCollab 연결이 필요하지 않습니다. 외부 링크를 직접 열 때만 원 사이트로 이동합니다.

| 명령                                      | 역할                                              |
| ----------------------------------------- | ------------------------------------------------- |
| `npm run dev`                             | Vite 로컬 개발 서버                               |
| `npm run typecheck`                       | TypeScript 엄격 모드 검사                         |
| `npm run lint`                            | TypeScript·수집 스크립트 ESLint 검사              |
| `npm run format` / `npm run format:check` | 자체 코드·문서 정렬 / 확인                        |
| `npm run build`                           | 타입검사 후 `dist/` 정적 빌드                     |
| `npm run preview`                         | 빌드 결과 로컬 확인                               |
| `npm run data:generate`                   | 저장된 응답에서 한국어 JSON 재생성, 네트워크 없음 |
| `npm run data:fetch`                      | PokeAPI 응답 8개를 순차 갱신하고 JSON 생성        |
| `npm run assets:sync`                     | 고정 커밋에서 샘플 시트·크레딧·정책 원문 재수집   |
| `npm run assets:verify`                   | 로컬 외부 파일의 출처 manifest와 SHA-256 비교     |

스크립트에서 실패하면 비정상 종료합니다. 데이터 수집 실패·한국어 누락·스냅샷 해시 불일치를 빈 데이터로 조용히 대체하지 않습니다. 생성 JSON과 원본 스냅샷은 함께 버전 관리하고, 원본 외부 파일은 포맷터 대상에서 제외합니다. `package-lock.json`을 함께 유지해 `npm ci`로 설치하세요.

## 역할 분리

```text
src/game/             DOM·에셋·네트워크에 독립적인 공통 타입
src/data/             최소 맵/상태 샘플, 포켓몬 데이터 어댑터
  sources/pokeapi/     원본 응답과 요청 URL·수집 시각·SHA-256
  generated/          가공한 한국어 JSON
src/assets/           에셋 조회, 고정 ID와 로컬 URL 연결
  vendor/             수정하지 않은 외부 PNG/XML/크레딧/정책
  generated/          제작자·조건·원본 URL·프레임·해시 manifest
src/ui/               준비 화면·스프라이트 재생·스타일
scripts/              재현 가능한 수집·가공·무결성 검증
docs/                 후속 계약과 원 출처 권리 검토 기록
```

후속 구현은 [공통 계약과 ID 규칙](docs/contracts.md)을 먼저 확인하세요. UI 준비 화면의 선택값은 `GameState`를 시작하거나 수정하지 않습니다. 런타임 검증·게임 reducer·저장은 후속 범위입니다.

## 스프라이트와 한국어 데이터

기본 4종에 대해 Idle·Walk **8개 PNG 시트**와 원본 XML을 로컬 보관합니다. 8방향 행과 XML의 프레임별 duration(60 tick/s)을 사용하며 3배 픽셀 확대만 표시 단계에서 적용합니다. 실험실에서 애니메이션·방향·정지·실패 재현을 바꿀 수 있습니다. 로딩 오류·8초 초과·에셋 누락 시 `?`와 한국어 상태로 대체하며, 실패 재현을 해제하면 다시 로드합니다. OS의 동작 줄이기 설정에서는 첫 프레임만 표시합니다.

데이터 수집 대상은 [scripts/samples.json](scripts/samples.json)에서 고정합니다. `pokemon/{id}`의 식별자·타입과 `pokemon-species/{id}`의 `names`·`genera` 중 `language.name === "ko"`인 값을 합칩니다. 지역 형태나 여러 폼의 ID 변환은 구현하지 않았습니다. 원본 응답 해시와 수집 시각은 각 `.source.json`과 가공 JSON에 보존합니다. REST 응답 자체는 변경될 수 있으므로 **동일 결과 재현에는 저장된 스냅샷과 `data:generate`를 사용**하세요. `data:fetch`는 명시적인 갱신 작업입니다.

[PokeAPI 공식 문서](https://pokeapi.co/docs/v2/)의 로컬 캐시 권고를 따릅니다. API 접근 정책과 포켓몬 콘텐츠의 저작권·상표권은 별개입니다.

## 권리와 크레딧

**자체 코드, 외부 에셋, 외부 데이터의 권리를 분리합니다.** `package.json`의 `UNLICENSED`는 자체 코드 라이선스가 미정이라는 표시이며, 외부 자료의 권리를 제한하거나 허락하는 표기가 아닙니다. 의존 패키지는 각 패키지의 라이선스를 따릅니다.

- Pokémon의 원작·캐릭터·명칭 관련 권리: Nintendo / Creatures Inc. / GAME FREAK inc. 등 원 권리자.
- Pokémon Mystery Dungeon 원작 스프라이트 관련 권리와 제작: Chunsoft / Spike Chunsoft 등. 원작 권리를 팬 제작자의 창작 기여 권리와 혼동하지 않습니다.
- 이미지 제공 경로: [PMD Sprite Repository](https://sprites.pmdcollab.org/) 및 [PMDCollab/SpriteCollab](https://github.com/PMDCollab/SpriteCollab).
- **이번 4종의 개별 제작자 기록은 모두 `CHUNSOFT`, 개별 라이선스는 `Unspecified`입니다.** 팬 제작자 이름을 임의로 붙이지 않았습니다. 일반 제출물에 대한 CC BY-NC 4.0 정책이 원작 추출물에 대한 허락을 보장한다고 주장하지 않습니다. 원 권리자의 별도 사용 허락은 확인되지 않았으며, 공개·재배포 전에 이를 별도로 검토해야 합니다.
- 팬 제출물을 추가할 때는 해당 슬롯의 제작자·기여 기록·라이선스·변경 내역을 개별 검토해 manifest와 안내에 반영해야 합니다. 원본 출처가 명시한 저작권·면책 고지도 유지하세요.
- 한국어 명칭 등 데이터 제공: [PokeAPI](https://pokeapi.co/docs/v2/). API 서버 코드의 라이선스를 데이터와 포켓몬 콘텐츠 전체의 라이선스로 간주하지 않습니다.

4종의 개별 제작자·기여 날짜·원본 URL·라이선스 식별자·수정 여부·해시는 [sprites.json](src/assets/generated/sprites.json)에 있으며 원본 `credits.txt`를 함께 보관합니다. 확인한 정책 원문과 예외는 [권리 검토 기록](docs/rights.md)을 참고하세요.

본 프로젝트는 공식 작품이 아니며 원 권리자 또는 SpriteCollab의 승인·제휴를 의미하지 않습니다. 비공식·비상업 안내만으로 별도 이용 허락이 생기는 것은 아닙니다.

### 권리자 삭제 요청

권리자의 요청이 있으면 해당 자료의 사용을 중지하고 저장소·빌드 결과에서 신속히 제거합니다. 요청 식별에는 대상 파일/URL, 권리 관계, 요청 범위가 필요합니다. **실제 요청 수신 창구는 아직 미정이며, 연락처나 요청 폼을 만들어 기재하지 않았습니다.** 공개하기 전에 운영자가 실제로 확인할 수 있는 창구와 담당자를 정해야 합니다.

전체 지도·가격·통행료·강화 단계·파산 정산·주사위 개수·승리 우선순위와 동시 달성 처리, 저장/이벤트 버전 정책, 최종 코드 라이선스, 외부 자료 재배포 허락, 삭제 요청 창구는 미정입니다. 이번 작업에서는 공개 배포·원격 푸시·머지를 하지 않습니다.
