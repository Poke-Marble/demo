# Poké Marble

포켓몬과 함께 관동·성도를 여행하는 비공식 보드게임입니다. **사람 1명과 AI 3명**이 32칸 보드에서 도시를 사고 시설을 지으며 경쟁합니다. 파트너의 고유 기술로 기회를 만들고 도시 독점이나 자산 경쟁으로 승리를 노려 보세요.

비상업 팬 프로젝트이며 금전적 이득을 목적으로 하지 않습니다. Nintendo, Creatures, GAME FREAK 또는 관련 권리자의 공식 작품이나 승인·제휴 프로젝트가 아닙니다.

## 플레이 방법

1. `NEW GAME`을 누르고 이상해씨·파이리·꼬부기·피카츄 중 파트너를 고릅니다. 나머지 세 파트너는 AI에게 배정됩니다.
2. 관동·성도 맵에서 표준 또는 짧은 경기 규칙을 선택합니다.
3. 주사위를 굴려 이동하고 도시 구매·시설 건설·통행료 지불·인수 등을 선택합니다. 필요한 금액과 가능한 행동은 화면에서 확인할 수 있습니다.
4. 기술을 쓸 기회가 오면 효과와 남은 PP를 확인하고 사용 여부를 정합니다. 내 차례를 마치면 AI가 같은 규칙으로 진행합니다.
5. 도시 목록에서 보드를 살펴보고 자산 화면에서 소유지를 검색하세요. 공중날기 칸에서는 보드에서 목적지를 고른 뒤 별도로 확정합니다. 선택한 파트너가 아머까오를 타고 도착합니다.

관동·성도에는 도시와 특별 명소, START, 공중날기와 루기아·칠색조를 만나는 칸이 있습니다. 다른 지방, 온라인 대전, 저장·이어하기는 지원하지 않습니다.

## 네 파트너의 고유 기술

각 파트너는 **3PP**로 시작합니다. PP는 자동으로 회복되지 않으며 개인 기본차례마다 기술을 한 번 사용할 수 있습니다.

| 파트너   | 기술     | 효과                                                        |
| -------- | -------- | ----------------------------------------------------------- |
| 이상해씨 | 덩굴채찍 | 주사위 눈을 본 뒤 이동 합계를 1 줄일 수 있습니다.           |
| 꼬부기   | 물대포   | 주사위 눈을 본 뒤 이동 합계를 1 늘릴 수 있습니다.           |
| 파이리   | 불꽃세례 | 도착한 곳의 의무 통행료를 25%, 최대 100 줄입니다.           |
| 피카츄   | 전기쇼크 | 인수할 수 있는 일반 도시의 인수금을 20%, 최대 100 줄입니다. |

이동 합계는 2~12 범위입니다. 원래 합계로 이동하면 PP를 쓰지 않습니다. 네 파트너 모두 고유 효과 대신 **기술 돌파**로 통행료를 15%, 최대 60 줄일 수도 있습니다. 기술 돌파와 고유 효과는 함께 사용하지 않습니다.

경제 기술은 유리한 상성에서 할인율이 10%p, 할인 상한이 25 늘어납니다. 우위 관계는 불→풀, 물→불, 풀→물, 전기→물입니다. 최종시설과 특별 명소는 인수할 수 없습니다. 자세한 효과와 사용 조건은 파트너 선택 화면과 경기 중 `기술 정보`에서 확인하세요.

## 주요 규칙

도시의 시설은 캠프→상점→포켓몬센터→최종시설 순서로 발전합니다. 개인 주회에 따라 건설 단계가 열리며 최종시설은 센터를 보유한 도시를 다시 방문해야 지을 수 있습니다.

일반 주사위 이동으로 START에 정확히 도착하면 소유 도시 한 곳의 다음 시설을 유료로 건설하거나 기회를 건너뛸 수 있습니다. 기술로 조정한 실제 이동도 포함하지만, START를 지나치거나 비행으로 도착한 경우는 제외합니다. 단계 해금과 비용은 유지하며, 이전 착지 때부터 센터가 완성돼 있었다면 이 START 기회가 최종시설의 재방문 조건을 대신합니다. 월급과 건설 결제는 별개입니다.

루기아·칠색조 칸에 도착하면 50을 받습니다. 각 칸에 서로 다른 세 참가자가 방문하면 집계가 초기화되고 전역 이벤트가 발동합니다. 루기아는 도시 통행료, 칠색조는 도시 시설 건설비를 25% 줄이며 발동 라운드와 다음 라운드가 끝날 때까지 유지됩니다. 토지·인수·명소에는 이 할인을 적용하지 않습니다. 각 참가자는 같은 집계에서 한 번만 셉니다.

| 규칙           | 표준               | 짧은 경기          |
| -------------- | ------------------ | ------------------ |
| 제한 라운드    | 30                 | 20                 |
| 캠프·상점 건설 | 처음부터           | 처음부터           |
| 센터 건설      | 개인 1주회 완료 후 | 개인 1주회 완료 후 |
| 최종시설 건설  | 개인 2주회 완료 후 | 개인 1주회 완료 후 |

모든 참가자가 기본차례를 한 번씩 마치면 한 라운드가 지납니다. 개인 주회는 각자 보드를 한 바퀴 도는 횟수입니다.

다음 중 하나를 달성하면 즉시 승리합니다.

- 마지막까지 파산하지 않고 남기
- 도시 그룹 3개 독점하기
- 보드 한 변의 일반 도시 모두 소유하기
- 특별 명소 4곳 소유하기

제한 라운드까지 승자가 없으면 마지막 차례의 정산을 마친 뒤 **현금 + 보유 토지 가격 + 누적 건설 원가**로 순위를 정합니다. 동점이면 현금이 많은 순, 이후 처음 정해진 좌석 순입니다.

## 설치와 실행

Node.js **22.17 이상**과 npm이 필요합니다. 저장소 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소(기본 `http://127.0.0.1:5173`)를 Chrome에서 엽니다. PowerShell이 `npm.ps1` 실행을 차단하면 `npm.cmd`를 사용하세요. 설치 후 게임에 필요한 이미지·글꼴·한국어 데이터는 로컬 파일을 사용합니다.

```sh
npm run build
npm run preview
```

빌드는 `dist/`에 생성됩니다. 코드 검사에는 `npm run typecheck`, `npm run lint`, `npm run format:check`를 사용할 수 있습니다. 데이터·에셋 출처와 개발 기록은 [docs](docs/), [데이터 수집 목록](scripts/samples.json), [에셋 manifest](src/assets/generated/sprites.json)에 있습니다.

## 소리와 접근성

`소리`에서 효과음의 음소거와 음량을 조절할 수 있습니다. 효과음은 브라우저에서 합성하며 사용자의 첫 조작 이후 재생됩니다. 소리 없이도 화면의 금액·안내·결과를 확인할 수 있습니다.

OS의 동작 줄이기 설정을 반영하며 연출을 건너뛸 수 있습니다. 메뉴는 키보드로 이동할 수 있고 대화상자는 닫기와 초점 이동을 지원합니다. 작은 화면의 긴 목록은 내부 스크롤로 살펴볼 수 있습니다. 이미지가 로드되지 않으면 대체 표시를 사용합니다.
